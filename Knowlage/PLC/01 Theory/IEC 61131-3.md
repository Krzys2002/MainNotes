## Definition
Standardize PLC languages, program organization units, data types, and common functions.

## Purpose
- Standardize PLC languages, program organization units, data types, and common functions.

## When To Use
Use this as the umbrella concept for LD, ST, FBD, SFC, functions, function blocks, and programs.

## Important Properties
- Defines POUs: programs, functions, and function blocks.
- Defines standard languages: LD, FBD, ST, SFC, and historically IL.
- Defines elementary data types, literals, variables, and standard function blocks.
- Improves portability, but vendor libraries and syntax still differ.

## Limitations
- Vendor-specific blocks and addressing remain common.
- Graphical languages are not exchanged perfectly between tools.

## Common Mistakes
- Confusing a function with a function block.
- Ignoring instance data for FBs.
- Assuming Siemens syntax is identical to CODESYS syntax.
